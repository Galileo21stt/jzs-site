# 中外建史 · 横向对比背诵站 — 交付说明

## 入口
- 网站：`/workspace/index.html`（单文件 HTML，内含全部 CSS/JS/数据，约 141KB；不依赖 CDN，双击即可离线打开）
- 图片：`site/img/orig/`（20 张原图原样复制）、`site/img/tiles/`（长图切成 1500px 宽的 JPEG 切片，手机/平板也能顺畅滚动）
- 源码与构建：`tools/src/*`，`node tools/build.js` 重新生成 index.html；`tools/prep_img.py` 负责复制和切片原图

## 内容来源与原则
- 文字只取自 `xhs_digest/notion.md`（打分精华 + 32 条勘误）和 `xhs_digest/transcript.md`（原长图的逐图转录）；原始素材目录只读，没有改动。
- 不确定的地方都做了标记：红色「错N」、黄色「可疑N」小标签，点开能看到教材依据，并链接到勘误页；原图里的错别字用灰色「原图作「…」」标出；原文没写的格子显示「—」或「未注明」，不补写。
- 自己画的示意图（金字塔剖面、太阳神庙纵轴、紫禁城中轴）都注明「示意，不按比例」。时间轴是顺序轴，只显示素材里写了的年份。

## 首页
- 分中建史 / 外建史两区，按价值高→中→低排序（中建：03 木构、01 建筑群、02 石构；外建：02、09、07、08、01、05、04、06、03）。
- 每张卡片包含：排名、价值、一句话理由、原长图缩略、可视化视图清单、勘误数量。

## 全站功能
- **原表格长图对照**：每个专题页都有「原图对照」浮动按钮（快捷键 O）。宽屏（≥1100px）时原图停靠在右侧，左右对照；手机/平板全屏打开。可切换 02/03/04.png、缩放、打开原始文件。
- **背诵模式**（快捷键 M）：可分别选择遮挡名词、作品、年代/数字，点灰条揭开、再点遮回，并统计「已揭开 x / y」；矩阵每列表头都有「遮」按钮，可以挡住整列。
- **自测页**：14 组卡片，包括闪卡和选择题（人物↔作品、作品→战后倾向、作品→后现代流派、流派→key、中建建筑→年代等），可以只练不熟的卡，进度保存在本机。
- **总时间轴**：外建 17 个时期 × 流派/人物/建筑/广场；中建按朝代分木构/砖石/宫殿陵寝园林。素材没注朝代的单独放一列。
- **其他**：全站搜索；勘误页（32 条，可按错/可疑筛选）。

## 自检
- 用 Chrome 156 headless + puppeteer（`tools/check.js`）在 1440×900 和 390×844（手机）两个尺寸下检查：所有 18 个路由都渲染了；逐页点击了筛选、挡列、关系图、选择题、原图开关/缩放/切图、背诵遮挡/全部揭开、勘误弹窗；也跑通了自测流程。
- 结果：JS 报错 0，控制台 error/warning 0，失败请求 0，手机宽度没有页面级横向溢出。`node --check` 语法检查通过。
