# 外国近现代建筑史时间树与关系练习

用时间为主干、思潮／流派为枝、人物为叶、作品与著作为花，服务人物归属、作品思想、理论著作、时间顺序等关系题。当前共 **58 组人物、38 条思想线索、112 项作品与著作、241 道自拟练习**。

本页是 `jzs-site` 的独立目录，不经过 `tools/build.js`；主站与其他工具沿用原有构建方式。

## 地址和路由

- 线上（合并到 main 后更新）：https://galileo21stt.github.io/jzs-site/tools/src/architect-links/
- `#tree`：时间树，可分组浏览、跳到时期；点枝、叶、花打开原位说明卡。
- `#movements`：流派目录，展开查看时代、产生背景、主张、关系边界、代表人物与教材出处。
- `#cards`、`#person/人物ID`：检索人物、别称、作品、思想；人物详情可回时间树定位。
- `#drill`：6道按用户所附题型改编的示例，以及作品→人物、人物→思潮、思想→人物、时间排序四种练习。
- `#quiz`：首版人物复述题与到期队列。
- `#graph`：横向对照与关系线索。
- `#progress`：人物自评、关系自评及导入导出。

主干自下而上分为五个可交叠的时期。每个思潮有独立枝条，枝内集中列出人物及其关联作品。跨专题人物另列，具体活动与作品年代见卡片。手机和宽屏使用同一张双侧白板，支持拖动平移和双指缩放。虚线表示跨专题关联。`技术转型`等是学习线索，`包豪斯`等是机构；没有把它们全部定义成同一性质的流派，也不把先后顺序写成直接师承。

## 内容与证据

- 新增39组人物和思潮说明，依据 `Galileo21stt/kaoyan1` main 的罗小未《外国近现代建筑史》第二版 OCR 文本核验。`sourceRef` 中的页码为教材印刷页码，部分由书末索引对照定位，不采用 `P#` 文本坐标或原PDF页冒充书页。
- 日期及作者有分期差异时参考馆方、大学档案、遗产机构等来源，并在卡片注明。柏林老博物馆、米拉公寓、理查兹研究楼、流水别墅等区分设计、施工、竣工或分期口径。
- 红屋在莫里斯卡中是关联案例，反向作者题明确归菲利普·韦布；合作作品保留合作署名说明。
- 仍有11组首版卡片未做逐项教材页码定位；详情及练习明确显示“首版学习卡；教材页码待定位”，不声称全库逐条核验完成。
- 新增练习为自拟／题型改编，不标注浙大真题年份、考频或用户掌握等级。思想反查为开放题，可能有其他合理例证。
- 时间排序只采用有 `sourceRef` 且日期为单一四位年份的作品，排除日期范围及方案／分期标注。
- 用户照片和教材原文没有上传本仓库。真实建筑图片保留外部图源检索入口。

## 数据和复习记录

| 文件 | 用途 |
|---|---|
| `data.js` | `PEOPLE`、`MOVEMENTS`、分组、关系线索和对照 |
| `study.js` | 用稳定ID生成自拟关系题，处理作品署名与同型题 |
| `app.js` | 页面、路由、检索、说明卡与自评记录 |
| `layout.js` | 时间树排布、线条裁剪、重叠检测、说明卡定位 |
| `interaction.js` | 节点点击优先级 |
| `styles.css`、`index.html` | 响应式样式与脚本入口 |
| `previews/` | 本次改版浏览器截图 |

人物原ID、顺序前缀、存储键 `arch-links-v1`、导出格式 `architect-links-review` v1 保留。关系练习增加可选 `relationReviews` 字段，与人物自评分开；旧导出文件仍可导入。导入按较新的日期合并，保留已有状态和草稿。复习数据仅存当前浏览器，不宣称跨设备同步。

自评“不会／模糊／会”分别安排1／3／7天后复测，每批最多10道。仅用户主动自评时写记录；浏览卡片不算掌握。新增人物还支持 `shortName`（树上简称）、`affiliations`（跨线索关联）、`sourceRef`、`workCredits`（反向作者题的精确署名）。
